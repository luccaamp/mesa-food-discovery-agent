# Delivery Hero Recommendation Dataset

This directory contains food delivery data spanning 3 cities:
    + Singapore (sg)
    + Stockholm (se)
    + Taiwan (tw)

Each city has its separate zipped sub-directory containing the following files:
    + orders_<city_code>.txt : contains all orders
    + orders_<city_code>_train.txt : contains orders for training set
    + orders_<city_code>_test.txt : contains orders for test set
    + products_<city_code>.txt : contains information for products available
    + vendors_<city_code>.txt : contains information for vendors available
